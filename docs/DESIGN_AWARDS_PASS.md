# Tracebench — Awwwards / premium craft pass (2026-09-20)

## Problem
UI read as cheap cyber: neon lime spam, ALL-CAPS mono noise, flat surfaces, broken Control Plane on Windows Chrome.

## Inspiration (principles, not clones)
- **Linear** — near-black canvas, hairlines, one accent, aggressive display tracking, restraint
- **Vercel** — typography as brand, no second accent, weight ≤600
- **Finout (Awwwards HM)** — FinOps instrument density without gamer chrome
- **Raycast** — precision dark utility, borders over shadows

## Direction (locked)
Phosphor Instrument, calmed:
- Canvas zinc `#09090b` ladder; phosphor accent used surgically (~3% pixels)
- Radius 4 / 6 / 8; no 12px+ balloons; no glass everywhere
- Sans for UI labels; mono only for IDs / metrics / logs
- Motion 120–180ms; Control Plane = flat 2D motion values (no CSS preserve-3d)
- Atmosphere (grain/grid) ≤30% opacity on marketing only

## Done when
Landing/story/shell/runs/ops/help feel like one expensive product; CPA reaches 100% with visible HITL settle on Windows Chrome; typecheck green; live on Vercel.
